# PersonalWebsite
Frontend course Fundamentals, first assignment - Build your personal Website

## Reflections: 

### What did you learn during this project?

Basics of HTML and CSS, how to start a new project, create a website, to use github and the terminal. New ways of working with AI, both good and bad. 

I learned new ways of structuring my workflow and how to adapt it to make it align with the flow of the course and lectures. I value that I learned what changes I need to make for better ways of learning in the future.

I also learned how I can have AI, in my case chatGPT, as an assistant. My main goal was to understand my code, I asked it to explain like a teacher which was very helpful both when I didn't know what to look for and when I had found something I didn't understand. 

### What was your biggest challenge, and how did you approach it?

This was my first project working with HTML and CSS, which made the learning curve both exciting and challenging. One of the main difficulties was managing time and maintaining steady progress when facing technical obstacles. It required developing patience and making decisions about when to keep refining a solution and when it was more effective to move forward.

From a technical perspective, I found CSS more challenging than HTML. However, this also made the process more rewarding, especially when layout and responsiveness started working as intended across different screen sizes.

### What are you most proud of in your site?

That it works, has responsivity and that I feel it is a good representation of me,not only in words but also with colors and fonts.
I didn't jump too far with AI, as I only let it explain things to me, and not write any code for me. It was very important for me to understand what happened and why. My page is cute and basic and I am proud that I am okay with that.
